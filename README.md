# Vault Hunter's Armory

A fast, searchable Borderlands 2 legendary and unique weapon farming reference. It contains 140 named guns across the base game and DLC, with acquisition sources, vanilla drop rates or costs, and notes for unusual cases.

## Features

- Search weapons, bosses, locations, manufacturers, and notes
- Filter by DLC/expansion, rarity, weapon type, and manufacturer
- Sort by release order, name, rarity, or simple drop percentage
- Detailed source and drop-rate views for weapons with multiple routes
- Shareable filter URLs and weapon links
- Responsive, dependency-free static site for GitHub Pages

## GitHub Pages

The site has no build step. In the repository settings, set **Pages → Build and deployment → Deploy from a branch**, then choose the `main` branch and `/ (root)` folder.

## Data scope

The database covers named guns in vanilla Borderlands 2: Legendary, Unique, E-Tech, Seraph, Pearlescent, and Effervescent rarities. Shields, grenades, relics, and class mods are outside this dataset. Quest rewards are shown as 100% when the relevant turn-in is selected. Special vendor costs, mission-bound items, formulas, and expired SHiFT codes retain their source wording.

Data was researched on July 22, 2026 using [Lootlemon](https://www.lootlemon.com/db/borderlands-2/weapons) and the [Borderlands Wiki](https://borderlands.fandom.com/wiki/Borderlands_2).
