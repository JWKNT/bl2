# Borderlands 2 Armory

A fast, searchable Borderlands 2 legendary and unique item farming reference. It contains 245 named items across the base game and DLC: 140 weapons, 26 grenades, 29 shields, 30 legendary class mods, and 20 relics. Each entry includes acquisition sources, vanilla drop rates or costs, and notes for unusual cases.

## Features

- Search items, bosses, locations, manufacturers, character classes, and notes
- Filter by category, DLC/expansion, rarity, item type, and manufacturer
- Sort by release order, name, rarity, or simple drop percentage
- Detailed source and drop-rate views for items with multiple routes
- Shareable filter URLs and item links
- Responsive, dependency-free static site for GitHub Pages

## GitHub Pages

The site has no build step. In the repository settings, set **Pages → Build and deployment → Deploy from a branch**, then choose the `main` branch and `/ (root)` folder.

## Data scope

The database covers named weapons, grenades, shields, legendary class mods, and relics in vanilla Borderlands 2. It includes Legendary, Unique, E-Tech, Seraph, Pearlescent, and Effervescent gear where those rarities apply. Generic non-legendary class-mod archetypes are excluded. Quest rewards are shown as 100% when the relevant turn-in is selected. Variable world pools, special vendor costs, mission-bound items, formulas, and expired SHiFT codes retain their source wording.

Data was researched on July 22, 2026 using [Lootlemon](https://www.lootlemon.com/db/borderlands-2/weapons) and the [Borderlands Wiki](https://borderlands.fandom.com/wiki/Borderlands_2).
